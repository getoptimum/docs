# Support

Ask in the validator support channel on [Discord](https://discord.gg/getoptimum). Console's **Support** link and **Trouble signing in?** point to the same server. Support and announcements both run there.

Partners Optimum onboards directly also have a dedicated Telegram group. Use it if you were given one.

Use support when an index is already claimed, a lookup limit stopped a submit, a gateway credential needs revoking on a self-serve account, or a report failed to load after a refresh. Include:

* the gateway id (`OPT_GATEWAY_ID`, which is the host name)
* the consensus client and its version
* the `failing` list from `curl http://localhost:48123/health`, if you have it
* what **Verify** on Signal shows

Do not paste the enrollment key or any other secret.

Invited operator accounts may also have **Help** → **Support** in the Console sidebar. Self-serve accounts do not get that group; use the Discord link above.

The [security audit](https://cdn.probelab.io/media/documents/2026-08-ProbeLab-Security_Audit_Report_Optimum_Gateway.pdf) is a published PDF, not a support channel.
