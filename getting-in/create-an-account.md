# Create an account

Open [Console](https://console.getoptimum.io/).

**Create account** and **Sign in** use the same two buttons:

* Continue with Google
* Continue with Microsoft

A new account continues into registration. An account that already has an organisation goes to the console.

The rail, once registration starts, is **Register org**, then **Connect**, then **Register keys** if you run validators. You can leave Connect with **I’ll do this later** and finish on **Signal**. You can leave validator indices with **Skip for now** and come back from the signup link.

The last screen is **Your account is ready**. It shows whether a gateway enrolled, how many indices you submitted (**Awaiting confirmation**), and **Go to the console**.

::: info
If [signup](https://console.getoptimum.io/signup) shows a 404, self-serve signup is closed. Optimum creates the account for you, and you sign in with the Google or Microsoft account you gave them. Where Signal and Accelerate are enabled for your organisation, you use the same screens.
:::
