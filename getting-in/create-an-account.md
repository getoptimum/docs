# Create an account

Open [Console](https://console.getoptimum.io/).

**Create account** and **Sign in** use the same two buttons:

* Continue with Google
* Continue with Microsoft

A new account continues into registration. An account that already has an organisation goes to the console.

The rail, once registration starts, is **Register org**, then **Connect**, then **Register keys** if you run validators. You can leave Connect with **I’ll do this later** and finish from the console. You can leave validator indices with **Skip for now** and come back from the signup link.

::: info
If [signup](https://console.getoptimum.io/signup) is not available, the account was created for you. Sign in with the same Google or Microsoft account. Signal and Accelerate, where they are enabled for your organisation, are the same screens.
:::
