# Register

The heading is **Your details** or **Your organisation**, depending on the account type.

## Entity

All of these are required.

* **Entity name**
* **Display name** — your Console org name
* **Registered address** — named as the Partner's address in the agreement
* **State or country of incorporation**
* **Your title** — recorded in the agreement's signature block

## Everyone

* **Do you run validators?** — Yes or No. Asked even when you have no beacon node.
* **Full name** — required. The person accepting, named in the signature block.
* **Username** — required. For an individual, this is your Console org name. An entity already set that as Display name.
* **Telegram handle** — optional
* **Contact email** — required. For notifications.

If you answer yes, Console also asks:

* **Total stake (ETH)**
* **Stake to connect to Optimum (ETH)**

There is no separate terms screen. On this screen, tick **I have read and agree to the terms**. The checkbox opens the agreement. **Accept the terms to continue** if you submit without it.

Submitting this screen is what creates the organisation. Connect is next when enrolment is available for the account. Otherwise you go to validator indices, if you run validators, or straight to a ready account.
